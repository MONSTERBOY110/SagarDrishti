SagarDrishti - vendored web fonts
=================================

Every face here is self-hosted rather than loaded from a CDN. That is a hard
requirement, not a preference: PRD F11 and CONTRIBUTING.md require the entire demo to
run air-gapped, and a font request to fonts.gstatic.com would break the offline
path the moment the WiFi is off on stage.

All are licensed under the SIL Open Font License 1.1, whose full text is in
OFL-1.1.txt beside this file.

How these files were obtained (reproducible)
--------------------------------------------------------------------------
Resolve the latin-subset woff2 URLs from the Google Fonts CSS API with a
modern browser user-agent, then download them:

  UA="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 \
(KHTML, like Gecko) Chrome/120.0 Safari/537.36"

  curl -A "$UA" \
    "https://fonts.googleapis.com/css2?family=Archivo+Narrow:wght@500;600;700&display=swap"
  curl -A "$UA" \
    "https://fonts.googleapis.com/css2?family=Courier+Prime:wght@400;700&display=swap"

Each response lists one woff2 per unicode subset; take the `latin` range. A
single file covering all requested weights is the signature of a variable
font, which is how Archivo Narrow arrives here as one file.

Retrieved 2026-09-07.
